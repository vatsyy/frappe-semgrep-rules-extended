# 01: Govern a reference Rule Candidate end to end

**What to build:** Make one test-only Rule Candidate travel through the complete
governance path—from Rule Contract and independently described evidence to a
catalogue decision and repository acceptance—so the foundation proves that an
unevidenced candidate cannot acquire trust through metadata or severity alone.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A versioned Rule Portfolio Catalogue represents one authoritative current
      entry per Rule Claim and retains append-only decision history.
- [ ] Rule Contract, Ground-Truth Case, Evidence Packet, scorecard, lifecycle,
      ownership, provenance, and cross-reference contracts are validated through
      the repository acceptance command.
- [ ] The reference candidate exercises the complete workflow without becoming
      production acceptance evidence; invented source remains explicitly
      test-only.
- [ ] Non-compensating gates produce a deterministic blocking, monitor, audit,
      or outside-portfolio result and reject unsupported measurements.
- [ ] Invalid schema versions, duplicate identities, incomplete contracts,
      missing evidence, broken history, and competing sources of truth fail with
      actionable diagnostics.
- [ ] Generated views are reproducible from canonical governance files, and the
      Frappe Upstream Mirror remains byte-identical.
